# Конкурсный пакет

## Scope
Проверить официальные правила и допустимость reuse, собрать actual AutoClaw build provenance, live demo video и черновик заявки.

## Acceptance
Нет утверждения что выиграл/подал без факта; submission только при явном внешнем действии, все claims соответствуют evidence.

Связанные проверки: AC-61 AC-62.

## Evidence
Command, exit code, artifact path, reviewed SHA/diff hash. Tests/release state are controlled by driver, not maker.
