# 90-second competition demo script
All accounts/data are synthetic unless a real participant explicitly consented to demo.

**0–10s:** Show permanent profile/QR. “This QR is mine, not the event's.” Scan from another phone/browser; public card loads without app.

**10–25s:** Show event import/claim. Profile already has confirmed registration context; participant adds only current need/offer and event-directory choice.

**25–45s:** Show recommendations with a concrete reason: “You need X; Bob offers X. Bob needs Y; you offer Y.” No claim that Bob already agreed.

**45–65s:** Alice requests intro → Bob accepts separately → selected contact fields reveal → each gets a suggested next step. Organizer dashboard increments mutual-intro aggregate but cannot see private note/contact.

**65–75s:** Alice revokes a public/reveal field and refreshes the other browser; field disappears. Show block/report/privacy quickly.

**75–85s:** Show Telegram round trip and exact staging/release SHA/test evidence. Optional WhatsApp/LinkedIn/Luma clearly labeled live or disabled.

**85–90s:** “Same profile works at the next meetup — that repeated use is the product hypothesis we’re testing.” Show reuse analytics placeholder only if backed by real pilot data; otherwise say “pilot metric”.
