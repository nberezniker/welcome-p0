# Бот: состояния и точные сообщения
Все тексты локализуются RU/EN/ES; ниже русская эталонная версия. `[значение]` подставляется из разрешённых данных, не выдумывается моделью.

| Триггер / состояние | Сообщение | Действия |
|---|---|---|
| Первый /start | «Привет! Здесь ваш профиль, QR и полезные знакомства. Выберите, с чего начать.» | Мой профиль · Мероприятие · Приватность |
| Профиль из регистрации найден после проверки | «Данные из регистрации на [событие] готовы. Проверьте имя и расскажите, кого ищете.» | Проверить профиль |
| Нет профиля | «Как к вам обращаться? Затем выберем, чем вы можете помочь и что ищете.» | Ввести имя · Продолжить в браузере |
| Готовность | «Профиль готов. По этому QR видны только выбранные вами публичные поля.» | Показать QR · Настроить поля |
| Event join | «Вы участвуете в [событие]. Хотите показывать профиль участникам и получать предложения знакомств?» | Включить · Пока нет |
| Нет кандидатов | «Пока не нашлось подходящих запросов. Можно уточнить, что вы ищете, или проверить позже.» | Уточнить запрос |
| Рекомендация | «[Имя] предлагает [X], который вы ищете. Вы можете помочь с [Y]. Предложить знакомство?» | Предложить · Пропустить |
| Запрос получателю | «[Имя] предлагает познакомиться на [событие]. [Краткое основание]. Выберите, какие контакты открыть при принятии.» | Посмотреть и принять · Отказать · Жалоба |
| Одна сторона согласна | «Запрос сохранён. Контакты откроются после ответа второй стороны.» | Отменить запрос |
| Обе согласны | «Вы оба согласились познакомиться. Разрешённые контакты и следующий шаг — в вашей карточке знакомства.» | Открыть знакомство |
| После события | «Сохранить следующий шаг по знакомству с [Имя]? Например, договориться о разговоре.» | Выбрать шаг · Без напоминаний |
| Marketing opt-in | «Хотите получать анонсы новых событий от [организатор]? Это не обязательно для участия.» | Подписаться · Не сейчас |
| /stop | «Рассылки в этом канале остановлены. Профиль остался доступен. Настройте отдельно события, знакомства и удаление аккаунта.» | Настройки · Удаление |
| Канал blocked | Никакого обхода блокировки; только server delivery state suppressed | — |
| /delete | «Удаление закроет профиль и доступ к знакомствам в WELCOME. Ранее скачанные другими людьми контакты могут остаться у них.» | Подтвердить в защищённой форме · Отмена |

Не прикладывать phone/email в уведомление о запросе до согласия. Не просить «напишите что угодно, чтобы увидеть визитку»: публичная визитка уже должна открываться по QR. Команда /stop должна иметь эффект до следующей queued отправки, а не только отвечать текстом.
