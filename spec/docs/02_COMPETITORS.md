## 2. Что именно разбивает прежнюю гипотезу
**Низкий порог входа уже существует.** Fotify прямо описывает browser-only вход, предодобренные email/CSV и mutual social reveal. Визиточные продукты уже позволяют постоянный QR. Поэтому отдельная функция не создаёт основания перейти.

**«AI» не покупательская причина сама по себе.** В карточке должно быть видно конкретное совпадение запроса/предложения, а после события — реальное действие. Слепой similarity score будет хуже простого списка людей, когда оба лишь ищут инвестора и не могут помочь друг другу.

**Организаторская база не принадлежит продукту автоматически.** Нельзя считать каждого импортированного гостя подписчиком WELCOME или клиентской рассылки. Иначе видимый рост будет состоять из недействительных/неактивных записей.

**Бесплатная карточка не доказывает бизнес.** Личный QR полезен автору проекта, но платёж организатора требует измеримого результата: меньше ручных интро, больше полезных встреч, повторные участия. Число посетителей лендинга этого не подтверждает.

## 3. Выбранное узкое преимущество — гипотеза
«Ваш личный профиль путешествует с вами. На каждой встрече меняется запрос, но не нужно заново создавать себя. Помощник напоминает не обо всём событии, а о следующем шаге в конкретном знакомстве».

Победить можно в выполнении этой цепочки для повторных малых B2B-событий: **registration reuse → 20-секундное подтверждение при наличии данных → 1–3 объяснимых знакомства → взаимное действие → личное повторное использование**. Срок 20 секунд — UX target для заранее заполненного профиля, не универсальное обещание на landing.

Не утверждать, что ни один конкурент не умеет всю цепочку. Проверять её в пользовательских тестах рядом с двумя ближайшими альтернативами: Blinq для личного режима и Fotify для event-режима.

## 4. Когда не стоит строить
Только нужна цифровая визитка — готовый сервис рациональнее. Нужно одно событие без долговременной личной сети — покупка existing event tool может быть дешевле. Нужны билеты, бейджи, спонсоры, сотни расписаний — не пытаться обогнать enterprise suite в конкурсном проходе.

Собственная разработка оправдана, если автор регулярно использует QR сам и имеет доступ к организаторам повторных событий, готовым раздавать ссылки. Это условия эксперимента, **не найденное доказательство спроса**.

## 5. Что ещё проверять руками, прежде чем называть продукт лучше
Одинаковый тест в WELCOME, Blinq, Fotify и одном WhatsApp event-assistant: время до просмотра контакта на чужом телефоне; необходимость регистрации; поведение существующего профиля на втором событии; видимость телефона до и после согласия; экспорт/удаление; follow-up без спама; функция offline; цена реального нужного тарифа. Снять screen recordings и пометить checked/not checked. В текущем исследовании такие paid-account тесты не выполнялись.
